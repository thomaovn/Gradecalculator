# Grade Calculator

A simple browser-based calculator for computing a final grade based on a weighted average of a written exam and a portfolio grade.

## Features

- Adjustable weighting between exam and portfolio (default: 60% / 40%)
- Sliders to set grades for exam and portfolio (A–F)
- Displays the calculated final grade with score and description
- Combination table showing all possible outcomes

## Usage

Open `karakterkalkulator.html` directly in a browser – no installation or server required.

1. Adjust the weights using the sliders at the top (exam % and portfolio %)
2. Set grades for the written exam and portfolio
3. The final grade updates automatically

## Grade Scale

| Grade | Description          |
|-------|----------------------|
| A (6) | Excellent performance |
| B (5) | Very good performance |
| C (4) | Good performance      |
| D (3) | Satisfactory performance |
| E (2) | Sufficient performance |
| F (1) | Fail                  |

## Technical

Pure HTML/CSS/JavaScript – no dependencies or build step.
